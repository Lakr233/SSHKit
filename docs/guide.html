Connect

Two entry points produce an SSHConnection. Scoped withConnection closes the session for you on the success and failure paths.

// Scoped (recommended)
let result = try await SSHClient.withConnection(configuration) { connection in
    try await connection.execute("uptime")
}

// Manual
let connection = try await SSHClient.connect(configuration: configuration)
defer { Task { try? await connection.close() } }
let report = connection.diagnosticReport()

Cancelling the surrounding Task aborts the in-flight operation by shutting down the underlying socket; the entire connection tears down. Open a fresh SSHConnection for the next attempt.

Authentication

SSHAuthentication is the auth method picker. Each case is constructed with its required inputs.

Password

let auth: SSHAuthentication = .password("hunter2")

Private key file

let auth: SSHAuthentication = .privateKeyFile(
    path: "/Users/me/.ssh/id_ed25519",
    passphrase: nil
)

Pass an OpenSSH PEM path. If the key is encrypted, supply the passphrase; otherwise pass nil (the default).

Keyboard-interactive

let auth: SSHAuthentication = .keyboardInteractive { name, instruction, prompts in
    // Return one response per prompt, in order. `echo == false` means do not display input.
    prompts.map { prompt in
        prompt.echo ? "deploy" : ""
    }
}

SSH agent

let auth: SSHAuthentication = .agent()
// Or pin a specific agent socket:
let pinned: SSHAuthentication = .agent(SSHAgentConfiguration(socketPath: "/tmp/agent.sock"))

Probing what the server offers

let discovery = try await SSHClient.discoverAuthenticationMethods(
    configuration: configuration
)
if discovery.methods.contains(.publicKey) {
    // route to private-key auth
}

Host trust

SSHHostKeyPolicy determines how the server's host key is validated. Pick one.

// 1. OpenSSH known_hosts file
let policy: SSHHostKeyPolicy = .knownHostsFile("/Users/me/.ssh/known_hosts")

// 2. SHA-256 fingerprint pin
let policy: SSHHostKeyPolicy = .pinnedFingerprint(
    SSHHostKeyFingerprint("SHA256:abcd…")
)

// 3. Inject any trust store
let policy: SSHHostKeyPolicy = .trustStore(SSHKeychainHostTrustStore())

// 4. Explicit insecure (testing only)
let policy: SSHHostKeyPolicy = .insecureAcceptAnyHostKey

The SSHHostTrustStore protocol is dependency-injectable. Two implementations ship with the package:

  • SSHMemoryHostTrustStore — volatile, useful for tests.
  • SSHKeychainHostTrustStore — persists SHA-256 fingerprints keyed by host:port in the Keychain. Default service name is wiki.qaq.sshkit.

The fingerprint passed to .pinnedFingerprint and stored in trust stores is normalized: if the raw value omits the SHA256: prefix, SSHKit adds it. After a successful connection, retrieve the live fingerprint with connection.hostKeyFingerprint; that is the value to persist for next time.

Commands

Two flavours.

Collected (batch)

let result = try await connection.execute("uname -a")
print(result.exitStatus)
print(String(data: result.standardOutput, encoding: .utf8) ?? "")

SSHCommandResult exposes standardOutput, standardError, exitStatus, and an optional exitSignal for remote signal termination.

Streamed

let command = try await connection.openCommand("tail -F /var/log/app.log")

for await event in command.events {
    switch event {
    case .standardOutput(let data):
        if let text = String(data: data, encoding: .utf8) { print(text, terminator: "") }
    case .standardError:
        break
    case .closed(let status, let signal):
        print("closed status=\(status) signal=\(signal ?? "-")")
        return
    }
}

events is an AsyncStream that finishes when the channel closes. You can write to the remote stdin while the stream is live (command.write(...)) and call command.sendEOF() / command.close().

PTY shell

let shell = try await connection.openShell(
    terminalType: "xterm-256color",
    columns: 120,
    rows: 32
) { event in
    if case .standardOutput(let data) = event {
        FileHandle.standardOutput.write(data)
    }
}

try await shell.write("ls -la\n")
try await shell.resize(columns: 200, rows: 50)
try await shell.close()

PTY-backed shells merge stderr into stdout (.standardError cases are reserved for non-PTY backends). The shell event handler runs off the worker queue; the closed event fires once with the channel exit status.

SFTP

Open an SFTP subsystem on the connection. While the SFTPClient is alive the connection is dedicated to it.

let sftp = try await connection.openSFTP()

// Listing
for entry in try await sftp.listDirectory("/var/log") {
    print(entry.filename, entry.attributes?.size ?? 0)
}

// Whole-file read/write
let data = try await sftp.readFile("/etc/hostname")
try await sftp.writeFile(Data("hello\n".utf8), to: "/tmp/hello.txt")

// File handles (for chunked I/O)
let handle = try await sftp.openFile(
    "/tmp/big.bin",
    flags: [.read],
    permissions: 0o600
)
while true {
    let chunk = try await handle.readData(maximumLength: 64 * 1024)
    if chunk.isEmpty { break }
    // process chunk
}
try await handle.close()

// Attributes & filesystem
let attributes = try await sftp.stat("/etc/hosts")
try await sftp.setPermissions(0o644, at: "/etc/hosts")
try await sftp.createDirectory("/tmp/staging", permissions: 0o755)
try await sftp.rename("/tmp/old", to: "/tmp/new")
try await sftp.createSymbolicLink("/tmp/link", targetPath: "/tmp/new")

// Transfers with progress
try await sftp.upload(
    localURL: URL(fileURLWithPath: "/Users/me/release.zip"),
    to: "/srv/release.zip"
) { sent, total in
    print("\(sent) / \(total)")
}
try await sftp.resumeDownload(
    remotePath: "/srv/release.zip",
    to: URL(fileURLWithPath: "/Users/me/release.zip")
)

resumeUpload and resumeDownload continue from the current local file size. Task cancellation tears down the underlying connection — subsequent operations on the same SFTPClient will fail.

SCP

SCP helpers are public extension SSHConnection — there is no separate SCPClient type. They open a one-shot streamed command and speak the SCP protocol over it.

try await connection.uploadFileWithSCP(
    localURL: URL(fileURLWithPath: "/Users/me/release.zip"),
    toRemotePath: "/srv/release.zip",
    permissions: 0o644,
    maximumSize: 64 * 1024 * 1024
)

try await connection.downloadFileWithSCP(
    remotePath: "/srv/release.zip",
    toLocalURL: URL(fileURLWithPath: "/Users/me/release.zip"),
    maximumSize: 64 * 1024 * 1024
)

SCP is a single-file path. maximumSize guards against runaway transfers and defaults to 64 MiB. Use SFTP for directory recursion, large transfers, or progress callbacks.

Forwarding & tunnels

Direct TCP channel

let channel = try await connection.openDirectTCPChannel(
    host: "10.0.0.5",
    port: 6379
)
try await channel.write(Data("PING\r\n".utf8))
let reply = try await channel.read(maximumLength: 64 * 1024)
try await channel.close()

Local forward (-L)

let forward = try await connection.startLocalForward(
    localHost: "127.0.0.1",
    localPort: 0,        // 0 = pick a free port
    remoteHost: "db.internal",
    remotePort: 5432
)
print("listening on \(forward.boundHost):\(forward.boundPort)")
try await forward.close()

Remote forward (-R)

let forward = try await connection.startRemoteForward(
    remoteHost: "127.0.0.1",
    remotePort: 0,
    localHost: "127.0.0.1",
    localPort: 8080
)

Dynamic SOCKS (-D)

let socks = try await connection.startDynamicForward(
    localHost: "127.0.0.1",
    localPort: 0,
    username: nil,
    password: nil
)
print("SOCKS5 endpoint: \(socks.boundHost):\(socks.boundPort)")

All forward objects expose the actually-bound boundHost / boundPort, useful when you passed 0 to let the kernel pick.

Proxy routes

Set proxyRoute on the configuration to reach the SSH endpoint through a SOCKS5 proxy, an HTTP CONNECT proxy, or another SSH host (ProxyJump).

// SOCKS5
configuration.proxyRoute = .socks5(SSHProxyEndpoint(
    host: "proxy.example",
    port: 1080,
    username: "u",
    password: "p"
))

// HTTP CONNECT
configuration.proxyRoute = .httpConnect(SSHProxyEndpoint(
    host: "proxy.example",
    port: 8080
))

// ProxyJump (jump host has full SSH credentials)
configuration.proxyRoute = .proxyJump(SSHJumpHost(
    host: "bastion.example",
    port: 22,
    username: "deploy",
    authentication: .agent(),
    hostKeyPolicy: .knownHostsFile("/Users/me/.ssh/known_hosts")
))

Diagnostics & logging

Attach an SSHLogHandler to receive structured events as they happen. The handler is invoked off the worker queue.

let recorder = SSHLogRecorder(capacity: 200)
configuration.logHandler = { event in recorder.record(event) }

let connection = try await SSHClient.connect(configuration: configuration)

// At any point, snapshot the redacted view:
let report = connection.diagnosticReport(
    phase: "post-connect",
    metadata: ["build": "1.2.3"],
    recentEvents: recorder.events
)

SSHLogRecorder stores events as a fixed-capacity ring of redacted entries (keys containing password, passphrase, secret, token, or privatekey are scrubbed). The diagnostic report does the same scrubbing before returning.

Algorithm profile

// Built-ins:
configuration.algorithmProfile = .modern        // libssh defaults + RSA >= 3072
configuration.algorithmProfile = .legacyRSA     // opts back into ssh-rsa, RSA >= 1024

// Custom (lists are passed straight to libssh; +/-/^ modifiers work):
configuration.algorithmProfile = SSHAlgorithmProfile(
    keyExchangeAlgorithms: "curve25519-sha256",
    macsClientToServer: "+hmac-sha2-512-etm@openssh.com",
    minimumRSAKeySize: 2048
)

// Inspect what libssh actually negotiates:
let snapshot = try configuration.algorithmProfile.inspectEffectiveAlgorithms()
print(snapshot.keyExchangeAlgorithms)

Latency probe

let report = try await SSHPortLatencyProbe.measure(
    configuration: configuration,
    serviceCommand: "true"
)
print("connect=\(report.connectDuration)s service=\(report.sshServiceDuration)s total=\(report.totalDuration)s")

The probe connects, runs serviceCommand, and disconnects. The returned report includes the active route (direct, SOCKS5, HTTP CONNECT, or ProxyJump).

Key generation

let pair = try SSHKeyGenerator.generateOpenSSHKeyPair(
    type: .ed25519,
    comment: "deploy@laptop",
    passphrase: nil
)
print(pair.authorizedKey)    // append to ~/.ssh/authorized_keys
print(pair.privateKeyOpenSSH) // OpenSSH PEM

Available types: .ed25519, .rsa(bits:) (default 3072), .ecdsaP256, .ecdsaP384, .ecdsaP521.
